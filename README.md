# Earworm

This is a tool to generate an "On Repeat" like playlist based on your top songs from [last.fm](https://last.fm).

You need [node.js](https://nodejs.org/en) to run this; fill in the appropriate details in `options.js` and then type `node .` into the console and follow the instructions!

- Run `node list.js` to see the list of songs in the console. Every time the code runs, the list gets logged in `list.json`.
